# Guided: launch (tier 3.3)

Copy this skeleton into `.launch-ready/STATE.md` and replace every `{{...}}`.

~~~markdown
# Launch state

Positioning: {{for whom, what job, versus which alternative}}
Hero: {{one sentence that a competitor could not claim}}
Share card: renders in {{previews checked}} on {{date}}.
Waitlist: {{provider}}; test signup delivered on {{date}}.
Attribution: every channel link carries utm_source.
Channels: {{channel}}: {{message written for that channel}}.
Plan: {{D-7 to D+7, one line per day}}.
~~~

Checklist:

1. Swap a competitor's name into the hero and every card. If a sentence still reads true, rewrite it.
2. Avoid "empower", "seamless", "unleash", and "supercharge".
3. Prepared is not published. Immediately before going public, run `arc-check.sh prepublish` and publish only on a pass. On a block, report the finding and stop; never accept the risk yourself.
